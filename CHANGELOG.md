# Changelog

## 1.0.0

First stable release of Nostalgic F3.

- Restores a familiar, fixed F3 layout with stable ordering, columns and spacing.
- Respects vanilla Debug Options and reduced-debug settings.
- Restores section-relative coordinates on the Block line and the total entity `T:` counter after particles.
- Handles vanilla and unknown mod output without hardcoded mod IDs, while separating the right-side system information cleanly.
- Supports Minecraft 1.21.9–1.21.11 and 26.1–26.3 with one matching jar per game version.
- Includes no configuration, Fabric API or other mod-library dependency.
